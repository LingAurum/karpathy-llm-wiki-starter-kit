# Obsidian Claude PKM

AI 驱动的 Obsidian 知识管理模板——碎片信息进，结构化概念出。

```
inbox/ ──→ sources/ ──→ wiki/
 捕获      消化         沉淀
```

## 为什么选这个

- **全中文模板与指令**：模板、规则、skill 文件全部用中文编写，零翻译摩擦
- **clone 即用**：Dataview 查询、笔记模板、AI 规则全部预置，打开就能跑
- **5 个预置 Dataview 查询**：最近入库、发布漏斗、候选概念、孤儿页面、高密度概念
- **内容创作者发布漏斗**：从"想法"到"已发布"的完整管线，一眼看清写作进度

## 快速上手

1. `git clone` 本仓库
2. 用 Obsidian 打开，信任社区插件
3. 把文章链接、灵感碎片扔进 `inbox/`
4. 运行入库指令，AI 整理到 `sources/`
