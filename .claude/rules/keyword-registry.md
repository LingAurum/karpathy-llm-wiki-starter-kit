# 关键词注册表

## 用途

定义 vault 中使用的关键词分类体系。ingest 和 compile 阶段根据此表为笔记打 tag。

## 分类

### 领域标签

| 标签 | 覆盖范围 |
|---|---|
| #AI | 人工智能、机器学习、深度学习 |
| #认知 | 认知科学、心理学、思维模型 |
| #效能 | 生产力、时间管理、工作流 |
| #写作 | 写作技巧、修辞、叙事 |
| #决策 | 决策理论、博弈、风险评估 |
| #工具 | 软件、框架、方法论 |

### 处理状态

| 标签 | 含义 |
|---|---|
| #待验证 | 声明未经充分来源支撑 |
| #已验证 | 声明经 2+ 独立来源确认 |
| #已证伪 | 声明被可靠证据推翻 |
| #核心 | 属于个人知识体系的核心节点 |

### 来源类型

| 标签 | 含义 |
|---|---|
| #文章 | 博客、公众号、网络文章 |
| #论文 | 学术论文、预印本 |
| #书籍 | 书籍章节摘要 |
| #播客 | 播客/视频摘要 |
| #对话 | 讨论记录、访谈笔记 |

## 使用规则

- 每篇笔记至少 1 个领域标签
- `#待验证` / `#已验证` / `#已证伪` 三选一，仅用于声明卡
- 来源类型标签仅用于素材摘要卡
