# review

## 功能

扫描 vault，标记过期内容，建议需要更新的笔记。

## 输入

- 整个 vault 笔记的 `updated` 字段和内容

## 处理流程

1. 检查 `updated` 字段，标记超过 90 天未更新的笔记
2. 检查 `status: 想法` 且超过 30 天未动的笔记
3. 检查含有 `[ ]` 未完成项且久未更新的笔记
4. 生成维护建议

## 输出

分三类列表：

**待更新** — `updated` 距今 > 90 天
**待推进** — `status: 想法` 且距今 > 30 天
**待清理** — 无入链且无出链的孤儿页面

每个条目附建议操作。
