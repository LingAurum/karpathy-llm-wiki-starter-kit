# 默认输出风格

## 语言

全部使用简体中文。术语首次出现可附英文原文。

## 摘要风格

- 3-5 句话，直接陈述核心信息
- 不用"本文"、"作者认为"等套话
- 信息密度高，每句话承载一个独立要点

## 概念表述

- 使用模板栏目结构（一句话定义 / 核心内容 / 关系 / 来源）
- 概念第一次出现用粗体标记
- wiki-link 格式引用其他概念：`[[概念名]]`

## 引用格式

- 引用来源使用 wiki-link：`[[来源笔记名]]`
- frontmatter 的 sources 字段使用列表格式

## 元规则

- 不给建议性评语（如"值得关注"、"建议阅读"），只陈述事实
- 不添加模板中未定义的自定义段落
