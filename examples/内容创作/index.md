# 内容创作 Demo

这个场景演示了如何用三层管道从碎片信息中提取写作概念。

## 数据流

```
inbox/                      sources/                    wiki/
───────                     ────────                    ────
AI写作工具的崛起      →     AI写作工具调研       ↘
关于写作流程的思考    →     写作流程方法论         →   AI辅助写作
Zettelkasten方法      →     Zettelkasten笔记法     →   写作流程
```

## 包含的笔记

- **3 篇 inbox** — 原始捕获：一篇公众号文章、一期播客、一篇方法论文
- **3 篇 sources** — AI 整理后的摘要，附概念提取和深挖方向
- **2 篇 wiki** — 从多来源交叉验证后编译的永久概念
